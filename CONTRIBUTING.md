# Contributing

Thanks for your interest in contributing to JetSeg! A few guidelines:

- Please open an issue first for significant changes or new model additions.
- Use Git LFS for any large model files; see README for commands.
- Write tests for new features and ensure `pytest` passes locally.
- Follow the existing code style and add type hints where helpful.

Small PR checklist:
- [ ] Add or update tests
- [ ] Update README or docs if user-facing behavior changes
- [ ] Include CHANGELOG entry
